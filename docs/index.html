Features

An assistant that actually does things

Not just a chatbot. Byte is wired into Windows, so your words turn into actions.

Completely hands-free

Say “Hey Byte”, click the orb, or press Ctrl+B. Byte hears when you stop talking and keeps listening for follow-ups.

Controls your desktop

Open apps and Store apps, websites and folders. Minimize or close windows, change volume and brightness, skip tracks.

Understands your screen

Ask “what does this error mean?” and Byte looks at your screen always after asking you first.

Timers & quick answers

Spoken timers and reminders, CPU and memory stats, web lookups, clipboard reading, and YouTube playback.

Remembers what you ask

Tell Byte your name or preferences and it remembers them. Follow-up questions work within a conversation.

Out of your way

A small orb that moves aside when you work, and lives in the system tray when hidden.

How it works

From your voice to done, in seconds

Every step can run on your own machine.

  1. 1

    Listen

    Byte records until you stop talking, then turns your speech into text.

    Whisper
  2. 2

    Think

    A language model works out what you want and which tool to use.

    Ollama · or OpenAI
  3. 3

    Act

    Byte runs the action natively and asks first before anything sensitive.

    Rust · Win32
  4. 4

    Speak

    The answer is spoken aloud in a natural voice, while the orb reacts.

    Piper

Your choice

Fully local, or cloud when you want it

Switch anytime in Settings. Speech recognition and the voice always stay on your PC.

Local · default

Private by design

Runs entirely on your computer through Ollama. Nothing leaves your device.

  • Use any Ollama model you like one for everything, or separate text and vision models
  • Suggested: granite4.2:3b + minicpm-v4.6
  • Works offline, no account, no cost
Cloud · optional

Bring your own OpenAI key

Paste an OpenAI API key for faster, smarter answers on any PC. OpenAI is the supported cloud provider for now.

  • One model handles text, tools and vision
  • Key stored in Windows Credential Manager
  • Choose any model, e.g. gpt-4.1-mini

Privacy

You stay in control

On-device by default

Your voice, requests and answers are processed on your own PC unless you choose cloud mode.

Asks before it acts

Byte asks for a spoken “yes” before it looks at your screen, and never claims to have done something it didn’t.

Forgets by default

Conversation context lives in memory only and clears after a short pause. Byte saves details only when you ask.

Keys kept safe

Cloud API keys are stored in Windows Credential Manager never in a plain-text file.

Get started

Up and running in four steps

1

Install Ollama and a model

Get Ollama for Windows and pull any models you like these are Byte's suggestions (about 4 GB). Or skip this and use an OpenAI key.

ollama pull granite4.2:3b
ollama pull minicpm-v4.6:latest
2

Add the speech engines

Byte currently supports Whisper for speech recognition and Piper for its voice. Download whisper.cpp with the ggml-tiny.en.bin model, and Piper with a high-quality voice. Put them in Byte's models folder:

# %APPDATA%\Byte\models
whisper-cli.exe
ggml-tiny.en.bin
piper.exe
en_US-lessac-high.onnx
en_US-lessac-high.onnx.json
3

Install Byte

Download the latest .msi installer from GitHub Releases and run it. Or build it yourself:

git clone https://github.com/Snaehath/Byte.git
cd Byte/src-tauri
cargo tauri build
4

Say “Hey Byte”

Byte opens with a quick setup. Choose Local or Cloud, then talk to it, click the orb, or press Ctrl+B. Find it in the system tray anytime.

  • Windows 10 or 11
  • A microphone
  • 8 GB RAM recommended for local models
  • Internet only for cloud mode and web tools

FAQ

Questions, answered

Is Byte free?

Yes. Byte itself is free, and local mode costs nothing to run. If you choose cloud mode, OpenAI bills your own account for the requests you make.

Does it work without the internet?

Yes. In local mode, speech recognition, the language models and the voice all run on your PC. Only web search, YouTube and cloud mode need a connection.

Do I need a powerful GPU?

No. The local models are small and run on most modern laptops, and a GPU just makes them faster. On machines with little video memory, cloud mode is the quickest option.

What does cloud mode send to OpenAI?

The text of your request, and a screenshot only when you ask Byte to look at your screen and confirm. Your voice recording never leaves your PC it's transcribed locally first.

Can I turn off the wake word?

Yes. Toggle it in Settings or from the tray menu. You can still talk to Byte by clicking the orb or pressing Ctrl+B.

Where can I report a bug?

Open an issue on GitHub. Byte keeps a log you can attach open it from the tray menu under “Open log folder”.
